Pre stavebný objekt SO 601 Príprava územia, ktorý je súčasťou Národného centra
rýchlostnej kanoistiky a veslovania, bolo príslušným stavebným úradom vydané Územné
rozhodnutie č.UKSP-127-TX1/2021-TN-1 z 21.07.2021, ktoré nadobudlo právoplatnosť
dňa 08.09.2021.
Pre navrhovanú činnosť „Národné centrum rýchlostnej kanoistiky a veslovania“,
ktorého objekt SO 601 je jeho súčasťou, bolo vydané rozhodnutie podľa zákona č.24/2006 Z.
o posudzovaní vplyvov na životné prostredie, Životného prostredia, Okresného úradu
Bratislava, odboru starostlivosti o životné prostredie č.OU-BA-OSZP3-2020/008346-055
z 08.10.2020, právoplatné 11.11.2020, podľa ktorého sa súhlasí s jeho realizáciou
s podmienkami.

Predkladaná projektová dokumentácia SO 301 a SO 601 je súčasťou pripravovaného
komplexu stavieb úseku Národného centra rýchlostnej kanoistiky a veslovania. Z dôvodu, že
SO 301 Kanál cieľ je vodná stavba, dokumentácia je prípravou ako samočinná časť. Výkresy
kanála budú použité ako súčasť SO 601 Príprava územia – Terénne úpravy, ktoré sú potrebné
pre ďalšie objekty, nakoľko nový terén sa v mieste navrhovaných objektov Centra rýchlostnej
kanoistiky zdvíha, aby sa zabránilo častému zaplavovaniu využívaného územia.
